## Global constraints

- CLAUDE.md rules: one purple (`primary`) button per screen (the way forward); tokens, never hex literals outside the
  token blocks at the top of `theme.css` / `a11y.css`; every font size `calc(Npx * var(--ts, 1) * var(--ls, 1))`;
  light theme and a 390 px phone checked; strings in all 7 locales via `node scripts/i18n-set.mjs <json>` (keep the JSON
  at `docs/superpowers/reports/i18n/game-nav-T<N>.json`); delete keys you stop using.
- From the spec's rules: only plates slant — text is never skewed, rotated or on a moving baseline; one angle, 12°, set
  in `em`; the slant lives on a decorative `::before`, the focusable element stays a rectangle with a `2px solid
  transparent` border; selected = inversion + size bump + gold edge (never purple fill); no looping motion, no
  `backdrop-filter`, no transition on Continue / Tip off; texture never under text; the tokens chip is display-only;
  nothing deeper than one click; no hover drop-downs.
- Italic and uppercase only for Latin scripts: `:lang(ja)`, `:lang(zh)`, `:lang(hi)`, `.a11y-font-modern`,
  `.a11y-font-readable` get `font-style: normal; font-synthesis-style: none; text-transform: none`.
- Forced colours and `.a11y-high-contrast` are both covered as the spec says (hide decoration, system colours, 7:1).
- `render()` rebuilds the page: any state (entrance flag, last values for the flash) lives in JS module state, not the
  DOM.
- Tests: TDD for any logic (pure helpers for the scorebug data, season track, numbering, ghost word, rail contents);
  CSS verified by screenshots. `npm test`, `npm run build`, `npm run format:check` green before each commit.
- Browser: `check:ui` hangs at High graphics here — add `graphics: 'low'` to the
  `JSON.stringify({ lightTheme: light, reducedMotion: true })` seed in `scripts/ui-check.mjs` while running it and
  revert before committing. Use `--only=<filter>`. Look at desktop dark, desktop light, phone, and add a high-contrast
  check (set `highContrast: true` in that seed for one run). Screenshots in `ui-shots/` (git-ignored).
- Commits: explicit `git add` paths; trailers `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` /
  `Claude-Session: https://claude.ai/code/session_01TJcs3aM2BUb2S8MMdWg1LU`; `git push origin ui-ease` after every
  commit; never push main, never force push, never merge. Known flakes under load: `tests/clothFit.test.js`, a `playsim`
