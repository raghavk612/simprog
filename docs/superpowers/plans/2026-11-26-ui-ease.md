## Shared hook (fixed now so packages can work in parallel)

A page's way forward on a phone sits in `<div class="page-action">…</div>`: the primary button, its disabled reason and
at most one short status line (e.g. "2 of 3 picked"). Packages A (Game day: Tip off / the next step and the skip line)
and B (Prep: Run the week with the plan count) wrap theirs in it; package E styles it — sticky above the tab bar at
≤ 620 px, ordinary flow on desktop — and uses it for the next-step slot of P1-12 on phones. Only one `.page-action` per
page.
